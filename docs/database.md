# Database

**Source:** `migrations/`, `internal/store/`, `sqlc.yaml`

## Database Type

- **Type:** PostgreSQL (pgx/v5 driver, pgxpool connection pool)
- **Migration Tool:** Goose (`pressly/goose`)
- **Query Generation:** sqlc

## Connection

- DSN from `datastores.postgres.dsn`
- Password injected from Kubernetes Secret (`datastores.postgres.password_secret`)
- Pool: `max_conns=20`, `min_conns=2`, `max_conn_lifetime=30m`, `max_conn_idle_time=5m`
- Health check every 30s via `pgxpool` health check callback

## Schema

All tables use `UUID` primary keys, `TIMESTAMPTZ` for timestamps, and `TEXT` (with `CHECK` constraints) instead of PostgreSQL ENUMs for status columns.

---

### `objects`

**Purpose:** Core metadata record for every managed object. Tracks lifecycle from pre-upload `pending` through completion to soft/hard deletion.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PK | Object ID (generated by application) |
| `tenant_id` | TEXT | NOT NULL | Tenant owning this object |
| `object_key` | TEXT | NOT NULL | Full S3 key: `{tenant_id}/{category}[/{subpath}]/{id}` |
| `bucket` | TEXT | NOT NULL | S3 bucket name |
| `content_type` | TEXT | NOT NULL | MIME type |
| `size_bytes` | BIGINT | NOT NULL | Declared size at upload time |
| `checksum_sha256` | TEXT | NULL | SHA-256 checksum (optional) |
| `status` | TEXT | CHECK | `pending`, `uploading`, `uploaded`, `complete`, `aborted`, `deleted`, `error`, `soft_deleted`, `hard_deleted` |
| `labels` | JSONB | DEFAULT `{}` | Arbitrary key-value metadata |
| `external_ref` | TEXT | NULL, UNIQUE per tenant | Caller-provided idempotency reference |
| `category` | TEXT | NOT NULL DEFAULT `objects` | Category slug |
| `subpath` | TEXT | NULL | Optional subpath within category |
| `stored_etag` | TEXT | NULL | ETag after S3 upload completion |
| `stored_size_bytes` | BIGINT | NULL | Actual stored size after completion |
| `completed_at` | TIMESTAMPTZ | NULL | When the object reached `complete` status |
| `deleted_at` | TIMESTAMPTZ | NULL | When the object was (soft-)deleted |
| `expires_at` | TIMESTAMPTZ | NULL | Expiry time for pending uploads |
| `created_at` | TIMESTAMPTZ | NOT NULL DEFAULT now() | Row creation time |
| `updated_at` | TIMESTAMPTZ | NOT NULL | Auto-managed by `set_updated_at()` trigger |

**PK Strategy:** Application-generated UUIDs passed at object creation.

**Key Constraints:**

- `UNIQUE (tenant_id, object_key)` — no duplicate keys per tenant
- `UNIQUE (tenant_id, external_ref)` (partial, where `external_ref IS NOT NULL`) — idempotency enforcement
- `CHECK (status IN (...))` — enforced status transitions
- `CHECK (category ~ '^[a-z0-9][a-z0-9_-]{0,62}$')` — slug format validation
- `CHECK (subpath ...)` — no path traversal, no leading/trailing slashes, max 256 chars

**Object Key Generation Trigger:** `enforce_object_key()` trigger on `INSERT` automatically computes `object_key = tenant_id/category[/subpath]/id`.

**Indexes:**

| Name | Columns | Type | Purpose |
|---|---|---|---|
| `uq_objects_tenant_key` | `(tenant_id, object_key)` | UNIQUE B-Tree | Uniqueness enforcement |
| `idx_objects_tenant_created_at` | `(tenant_id, created_at DESC)` | B-Tree | Default listing sort |
| `idx_objects_tenant_status_created` | `(tenant_id, status, created_at DESC)` | B-Tree | Status-filtered listing |
| `idx_objects_tenant_external_ref` | `(tenant_id, external_ref)` WHERE IS NOT NULL | Partial B-Tree | Idempotency lookups |
| `idx_objects_pending_expires` | `(expires_at)` WHERE `status='pending'` | Partial B-Tree | Reaper queries |
| `idx_objects_tenant_category_created` | `(tenant_id, category, created_at DESC)` | B-Tree | Category-filtered listing |
| `idx_objects_tenant_category_status_created` | `(tenant_id, category, status, created_at DESC)` | B-Tree | Category + status listing |
| `idx_objects_tenant_category_extref` | `(tenant_id, category, external_ref)` WHERE IS NOT NULL | Partial | Category idempotency |
| `idx_objects_key_prefix` | `(tenant_id, object_key text_pattern_ops)` | B-Tree (text_pattern_ops) | Prefix searches |

**RLS Policy:** `tenant_isolation_objects` — `USING (tenant_id = current_setting('app.tenant_id', true))` (enabled by migration 003, controlled by `security.enable_rls`).

### `multipart_uploads`

**Purpose:** Tracks the state of in-progress S3 multipart uploads. Each row corresponds to an ongoing or completed multipart session.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PK | Internal multipart record ID |
| `tenant_id` | TEXT | NOT NULL | Owning tenant |
| `object_id` | UUID | FK → objects(id) ON DELETE CASCADE | Associated object |
| `upload_id` | TEXT | NOT NULL | S3 multipart upload ID |
| `bucket` | TEXT | NOT NULL | S3 bucket |
| `object_key` | TEXT | NOT NULL | S3 key |
| `content_type` | TEXT | NOT NULL | MIME type |
| `part_size_bytes` | BIGINT | NOT NULL | Per-part size in bytes |
| `status` | TEXT | CHECK | `initiated`, `uploaded`, `completed`, `aborted`, `expired` |
| `expires_at` | TIMESTAMPTZ | NOT NULL | When this upload session expires |
| `created_at` | TIMESTAMPTZ | NOT NULL | Creation time |
| `updated_at` | TIMESTAMPTZ | NOT NULL | Auto-managed by trigger |

**Indexes:**

| Name | Columns | Purpose |
|---|---|---|
| `uq_mpu_tenant_upload` | `(tenant_id, upload_id)` UNIQUE | Fast lookups by upload_id |
| `idx_mpu_tenant_created_at` | `(tenant_id, created_at DESC)` | Listing |
| `idx_multipart_tenant_status` | `(tenant_id, status, created_at DESC)` | Status filtering |

**RLS Policy:** `tenant_isolation_multipart_uploads` — same `app.tenant_id` pattern.

### `multipart_parts`

**Purpose:** Optional tracking of individual parts uploaded in a multipart session.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `multipart_id` | UUID | FK → multipart_uploads(id) ON DELETE CASCADE | Parent multipart session |
| `part_number` | INT | PK (composite) | Part number (1-based) |
| `etag` | TEXT | NULL | Part ETag from S3 |
| `size_bytes` | BIGINT | NULL | Part size |
| `created_at` | TIMESTAMPTZ | NOT NULL | Creation time |

**Indexes:** `idx_mpp_multipart_id` on `(multipart_id)`

**RLS Policy:** `tenant_isolation_multipart_parts` — `USING (multipart_id IN (SELECT id FROM multipart_uploads))` which inherits multipart_uploads RLS.

### `idempotency_keys`

**Purpose:** Stores results of idempotency-keyed requests to enable safe retries. Keyed by `(tenant_id, idempotency_key)`.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `tenant_id` | TEXT | PK (composite) | Owning tenant |
| `idempotency_key` | TEXT | PK (composite) | Client-provided idempotency key |
| `request_path` | TEXT | NOT NULL | Request path |
| `request_hash` | TEXT | NOT NULL | SHA-256 of the request body |
| `response_code` | INTEGER | NOT NULL | HTTP response code to replay |
| `response_body` | JSONB | NOT NULL | HTTP response body to replay |
| `created_at` | TIMESTAMPTZ | NOT NULL | Creation time |
| `expires_at` | TIMESTAMPTZ | NOT NULL | Expiry time (configurable via `idempotency.ttl`) |

**RLS Policy:** `tenant_isolation_idempotency` — `USING (tenant_id = current_setting('app.tenant_id', true))`.

### `audit_logs`

**Purpose:** Append-only audit trail of API requests. Written by the HTTP audit middleware.

| Column | Type | Description |
|---|---|---|
| `id` | UUID | PK |
| `tenant_id` | TEXT | Owning tenant |
| `request_id` | TEXT | Correlation ID |
| `idempotency_key` | TEXT | Idempotency key if present |
| `actor_subject` | TEXT | Actor identity |
| `actor_type` | TEXT | `user`, `service`, or `system` |
| `client_ip` | INET | Client IP address |
| `user_agent` | TEXT | HTTP User-Agent header |
| `method` | TEXT | HTTP method |
| `path` | TEXT | Request path |
| `query_params` | JSONB | Query string params |
| `request_headers` | JSONB | Request headers (sensitive headers redacted) |
| `request_body_sha256` | TEXT | SHA-256 of request body |
| `request_size_bytes` | BIGINT | Request body size |
| `http_status` | INT | Response HTTP status code |
| `response_code` | TEXT | Application error code (if any) |
| `response_status` | TEXT | Response status label |
| `response_time_ms` | INT | Latency in ms |
| `created_at` | TIMESTAMPTZ | Append timestamp |

**Indexes:**

- `idx_audit_logs_tenant_created_at` — `(tenant_id, created_at DESC)` — primary listing
- `idx_audit_logs_tenant_path_created_at` — path-based filtering
- `idx_audit_logs_tenant_status_created_at` — status-based filtering
- `idx_audit_logs_tenant_request_id` (partial) — request ID lookups
- `idx_audit_logs_tenant_idempotency_key` (partial) — idempotency correlation
- `idx_audit_logs_brin_created_at` — BRIN for bulk time-based pruning
- `idx_audit_logs_tenant_created_id` — `(tenant_id, created_at DESC, id DESC)` — deterministic pagination
- `idx_audit_logs_tenant_path_prefix` — `text_pattern_ops` for prefix searches

**RLS Policy:** `tenant_isolation_audit_logs`

### `object_categories`

**Purpose:** Tenant-scoped category registry. Objects must belong to a valid category slug for the tenant.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | UUID | PK, DEFAULT `gen_random_uuid()` | Category ID |
| `tenant_id` | TEXT | NOT NULL | Owning tenant |
| `slug` | TEXT | NOT NULL, regex validated | Category slug (`[a-z0-9][a-z0-9_-]{0,62}`) |
| `name` | TEXT | NOT NULL | Human-readable display name |
| `description` | TEXT | NULL | Optional description |
| `created_at` | TIMESTAMPTZ | NOT NULL | Creation time |
| `updated_at` | TIMESTAMPTZ | NOT NULL | Auto-managed by trigger |

**Unique constraint:** `(tenant_id, slug)` — one slug per tenant.

**Indexes:**

- `uq_object_categories_tenant_slug` — (unique constraint used as index)
- `idx_object_categories_tenant_created` — `(tenant_id, created_at DESC)` — listing

**RLS Policy:** `tenant_isolation_object_categories`

## Transactions

- Unit-of-Work pattern via `UoWFactory` (`internal/store/uow.go`) for operations requiring atomic DB + S3 coordination.
- Individual store methods use `pgxpool` connections; no custom isolation level is set (defaults to PostgreSQL `READ COMMITTED`).

## Data Lifecycle

| Entity | Deletion Type | Trigger |
|---|---|---|
| `objects` | Soft (`soft_deleted`) → Hard (`hard_deleted`) | Business logic via `DeleteObject` / `PurgeObject` |
| `multipart_uploads` | Status: `aborted` / `expired` | Reaper worker + explicit `AbortMultipart` |
| `idempotency_keys` | Hard delete by expiry | Reaper or TTL-based cleanup |
| `audit_logs` | Hard delete by TTL | Reaper (`cleanupAuditLogs`, batch 1000) |
| `tenants` | Hard delete | Admin `DeleteTenant` RPC |
