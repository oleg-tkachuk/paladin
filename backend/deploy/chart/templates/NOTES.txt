{{ include "chart.fullname" . }} ({{ .Chart.AppVersion }}) installed in {{ .Release.Namespace }}.

Paladin runs as one binary in multiple Deployments — one per role:

  api      data Connect listener (public-ish traffic)
  iam      IAM Connect listener, OAuth AS and session JWKS (holds the session key)
  admin    admin Connect listener (privileged operations)
  worker   background jobs with Postgres-leased leadership
  mcp      Model Context Protocol bridge (LLM-facing)
  session  the console's session (only with deployments.session.enabled)

Migrate + bootstrap ran as Helm hook Jobs before any Deployment rolled.

Reach the data plane:
{{- $scheme := include "chart.internalScheme" . }}
{{- $apiSvc := include "chart.roleFullname" (dict "ctx" . "role" "api") }}

{{- if .Values.ingress.enabled }}

  Via the {{ .Values.ingress.className }} Ingress:
    {{- range .Values.ingress.hosts }}
    curl https://{{ . }}/livez
    {{- end }}

{{- else if and .Values.traefik.enabled (gt (len .Values.traefik.hosts) 0) }}

  Via Traefik IngressRoute:
    {{- range .Values.traefik.hosts }}
    curl http{{ if $.Values.tls.enabled }}s{{ end }}://{{ . }}/livez
    {{- end }}

{{- else }}

  Via port-forward (api Service):
    kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $apiSvc }} {{ .Values.ingress.data.port }}:{{ .Values.ingress.data.port }}
    curl {{ if eq $scheme "https" }}-k {{ end }}{{ $scheme }}://localhost:{{ .Values.ingress.data.port }}/livez

{{- end }}

{{- if .Values.config.bootstrap.admin.enabled }}

Sign in as the platform admin, subject `{{ .Values.config.bootstrap.admin.subject }}`:

  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.config.bootstrap.admin.password_secret.name }} \
    -o jsonpath='{.data.{{ .Values.config.bootstrap.admin.password_secret.key }}}' | base64 -d

──────────────────────────────────────────────────────────────────────────

Disable a role: `--set deployments.<role>.enabled=false`. Toggling the
api role takes the data plane offline, the iam role login and token refresh; toggling the worker or mcp
roles is safe (no client traffic).

Worker leases, via psql:
    SELECT name, holder_id, expires_at, generation FROM worker_leases;
